# Blog-Firefly

基于 [CuteLeaf/Firefly](https://github.com/CuteLeaf/Firefly) 二次开发的个人博客。

## 新增功能

- **Obsidian 文章同步**：将标记为博客内容的 Obsidian 笔记同步到站点，支持新增、更新和同步。
- **稳定的文章链接**：自动为文章生成独立 slug，支持随机或拼音形式；文章重命名或移动后，已有链接保持不变。
- **Footer 页面置底**：内容较少时，Footer 仍保持在页面底部。
- **圆形动态头像**：侧边栏头像采用响应式圆形裁切，并在鼠标悬停时旋转。

上游 Firefly 仍在持续更新；完整的主题功能、安装方法和配置说明请查阅[上游 README](https://github.com/CuteLeaf/Firefly#readme)与[上游官方文档](https://docs-firefly.cuteleaf.cn/)。
